# Pairpoint / Vodafone status

Official Allora material dated 2026-06-17 describes a **Proof of Concept** with Pairpoint by Vodafone for EV route and charging optimization. It specifies three conceptual prediction topics including energy consumption / arrival state-of-charge and charger availability at ETA, with scoring and ground-truth concepts.

This is not evidence that those topics are live on Allora mainnet. The 2026-08-10 mainnet census contains only crypto market topics and no Pairpoint/EV topic.

No public live-topic identifier, live reward economics, or complete dataset/specification sufficient to recreate the real PoC was treated as available. Consequently this repository uses only `tests/fixtures/synthetic_non_trading.json`, explicitly labeled `SYNTHETIC_TEST_FIXTURE` and `economic_evidence=false`, to validate the generic shadow-worker interfaces.
