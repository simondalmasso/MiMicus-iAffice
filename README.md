# MiMicus Swarm

MiMicus V0.1 is a research implementation of an **agentic immune swarm**: it selects a task-specific coalition, runs sealed independent first passes, executes cheap deterministic falsifiers, gates persistent memory by evidence authority, and records an append-only replayable provenance ledger.

The repository does **not** claim that MiMicus is the world's first immune swarm, that it eliminates model collisions, or that it is superior to all multi-agent baselines. Those are empirical questions. `mimicus benchmark` provides a deterministic benchmark harness intended to make such claims testable rather than rhetorical.

## Core thesis

> MiMicus does not learn which agent sounds smartest. It learns which verified tests expose which classes of error, selects a task-specific coalition to run the cheapest decisive tests, and refuses to let unverified memory or self-mutations acquire authority.

## V0.1 properties

- Python 3.12 reference runtime.
- Dynamic morphology: one agent for simple tasks, larger sparse coalitions only when the threat profile needs complementary capabilities.
- Hidden micro-auditions and domain-scoped calibration before routing.
- Sealed first-pass generation; no peer answer sharing before independent claims exist.
- Declarative `FalsifierSpec` DSL over five trusted primitives. Database/model text is never executed as Python or another programming language.
- K3 behavioral lineage preserved by hash and compatibility vectors, implemented clean-room rather than by executing legacy raw scripts.
- Four memory gates: WRITE, RETRIEVAL, PROMOTION, CROSS-AGENT.
- Declarative germinal mutation against a frozen 100-fossil corpus, with immutable parents and deterministic promotion gates.
- Hash-chained event ledger and replay/tamper detection.
- SQLite by default; SQLAlchemy schema compiles for PostgreSQL.
- OpenAI Agents SDK provider and credential-free scripted provider.
- Official MCP Python SDK Streamable HTTP endpoint at `/mcp`.

## Locked install

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.lock
python -m pip install --no-deps -e .
mimicus doctor --profile offline
```

`requirements.lock` is generated from the resolved Python 3.12 environment and is verified in CI. The project metadata also pins direct runtime and development dependencies.

## Offline reference run

```bash
mimicus db upgrade
mimicus run --profile offline --task-file fixtures/tam_12x.json --budget-usd 0 --max-agents 4 --depth normal --learn
mimicus replay <run_id>
mimicus benchmark --profile offline --episodes 200 --output-dir evidence/ORDER-002
```

Offline mode requires no model API key and is the normative reproducibility path.

## OpenAI profile

Set `OPENAI_API_KEY` in the environment and run with `--profile openai`. The online provider uses the OpenAI Agents SDK as the model-facing runtime; MiMicus still owns coalition selection, falsification, trust, memory, communication topology, and mutation. No live credential is required for the ORDER-002 offline DONE gate.

## MCP

mimicus serve --profile offline --host 0.0.0.0 --port 8765

## Security boundary

MiMicus does not execute code generated by an LLM or stored in its database. Runtime falsifier mutations are validated Pydantic data structures composed only from trusted source-controlled primitives. Out-of-tree plugins require an explicit allow-listed path plus SHA-256 match. See `SECURITY.md`, `docs/THREAT_MODEL.md`, `docs/K3_SEED_LINEAGE.md`, and `docs/RESEARCH_LINEAGE.md`.
